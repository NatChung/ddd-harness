# 需求 → spec 包(v4)

跑 `/grilling` 當訪談引擎,全程記 `INTERVIEW-LOG.md`(每題:Q、A、來源、落點)。
每敲定一條決策,立刻按型態落檔:**詞 → GLOSSARY、行為 → SPEC 的 GWT、
結構 → ARCHITECTURE**;被否決或延後的需求,落 SPEC 的「明確不在範圍」。

落檔完、收尾前,跑一次**五尺度盤點**(每尺度:有落點,或明寫空缺;
漏格 = 訪談還沒完):

> **出處與證據等級**:「五個層層嵌套的尺度」出自 Teddy(陳建村)「馴服 AI」
> 工作坊的**課程行銷頁**。但**下表每個尺度配哪個檢查,是本 workspace 從課綱反推的,
> 不是 Teddy 公開的內容** —— 沒上過課、沒看過教材。推導過程寫在一份自標
> 「Teddy 側 = 推斷」的比較筆記裡,**那份筆記沒有隨這個 repo 發布**(留在私人筆記 repo)。
> 對外講的時候要標這一層,不要說成是他的框架。

| 尺度 | 檢查 |
|---|---|
| 需求 | 每個行為都有 GWT? |
| 大(架構) | 本案特有的架構規則都進 ARCHITECTURE? |
| 中(agent 職責) | 屬 harness 過程層,不進 spec 包——允許「明寫空缺:本輪單 agent」 |
| 小(命名) | 命名鐵律與禁用清單齊? |
| 微(契約) | 每條領域契約有 DbC 標籤?postcondition 至少含:每條失敗路徑的狀態保證(原子性/不留殘骸)?失敗路徑清單必含「系統中途失敗(如持久化中途失敗)」,且該路徑有指名測試(模擬中途失敗,不得空洞通過)? |

## 產出合約(五份,缺一即未完成)

1. **GLOSSARY.md** — ubiquitous language 表:每詞給型態(標準 DDD 詞:
   Aggregate Root、Value Object、Repository、…)、一句定義、所屬層。
   量值的詞(金額、時間)必須定死單位與表示法(例:金額一律 cents 整數)。
   開頭寫死:「實作命名必須照此表,不得另創同義詞」+ 禁用同義詞清單。
2. **SPEC.md** — 端點清單(不多不少)+ 行為情境:每條 Given-When-Then 有
   具體前提資料、單一動作、可斷言結果(能一比一翻成自動化測試),數字單位無歧義。
   **端點那節必須逐欄寫明對外的 JSON 欄位名**(請求的每個欄位、回應與列表一列的
   每個欄位)。stakeholder 不懂技術、問他欄位名沒有意義,所以這裡標 `本案自決`
   是對的 —— **但自決完必須落成合約,不能只寫「HTTP 形式本案自決」就算了。**
   理由(2026-08-18 實測):欄位名沒定,兩個模型會各取各的名字,**兩邊都不會過**,
   那套驗收就判定不了任何事 —— 而失敗訊息全是 `but was: null`,
   領域行為對不對完全看不見。見 `docs/adr/0004`。
   **「領域契約(Design by Contract)」獨立一節**(節名用此名,不另立
   CONTRACTS.md;契約編號 C1、C2、…),與情境同等效力,**每條標 DbC 型態
   (precondition / postcondition / invariant),並註明配哪個指名測試、
   或一句說明為何不配**。結尾「明確不在範圍」:逐項列,
   **每項標來源(訪談否決 / 規格沉默)**,收尾「不要做」。
3. **ARCHITECTURE.md** — 從常備模板起筆(package 佈局、相依方向、框架隔離),
   只追加本案特有規則(邊界例外、讀寫佈局),標注哪些由機械檢查強制。
   **每條規則標出處:「模板既定」或「本案自決」**——標既定者必須逐字有據
   於模板/工程前提;自決者須有 [Qn] 或 ASSUMPTIONS 依據。
   嚴禁把自決偽裝成既定。
4. **PROMPT.md** — 給實作 agent 的工作契約:凍結清單(不得修改的檔案)、
   要填的範圍、完成的定義(測試全綠)、歧義自決並逐條記 ASSUMPTIONS.md。
5. **INTERVIEW-LOG.md** — 訪談紀錄。SPEC 與 GLOSSARY 的每條規則標 `[Qn]`
   回鏈至此;查無對應問答的規則 = 捏造,不得存在。

## 完成判準

- 五尺度盤點無漏格(每格:落點,或明寫空缺)。
- 訪談的每條決策指得出落點;每條 GWT 的 Then 可斷言;每條規則有 `[Qn]`。
- 沒問過 stakeholder 的事 = 規格沉默:寧可入「明確不在範圍」,也不默默展開。
